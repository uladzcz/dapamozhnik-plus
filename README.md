# Дапаможнік+ (Dapamozhnik Plus)

> **Адкрытая геаінфармацыйная і аналітычная платформа па гістарычных паселішчах і прозвішчах Беларусі.**

Платформа аб'ядноўвае і аналізуе архіўныя звесткі XVIII–XX стагоддзяў, дазваляе даследаваць паходжанне і арэалы прозвішчаў, фанетычныя суфіксы (фіналі), рэгіянальнае дамінаванне па 118 раёнах Беларусі і праглядаць вёскі на гістарычных картах.

---

## 📊 Маштаб базы звестак

* **46 914 паселішчаў** (вёскі, мястэчкі, засценкі, фальваркі, хутары, у тым ліку зніклыя ці перайменаваныя).
* **64 194 унікальныя прозвішчы**.
* **343 000+ архіўных прывязак** (маёнткі і ўласнікі Сапегі, Радзівілы і інш. XVIII–XIX стст., праваслаўныя і каталіцкія прыходы, паветы, уезды, воласці).
* **43 000+ кропак з дакладнымі GPS-каардынатамі**.

## ✨ Асноўныя магчымасці

1. **Інтэлектуальны пошук з нармалізацыяй:**
   * Уніфікацыя апострафаў (`’`, `ʼ`, `'`).
   * Мульты-слоўны пошук незалежна ад парадку слоў (*«Вулька Аброўская»* знаходзіць *«Аброўская Вулька»*).
   * Фанетычная талерантнасць да акання і варыянтаў напісання (*«Церахавічы»* знаходзіць *«Цераховічы»*).
   * Пошук па маёнтках, уласнікаў, уездах, валасцях і царкоўных прыходах.

2. **Геаграфія фіналяў (Суфіксы прозвішчаў):**
   * Аналіз найбуйнейшых беларускіх пластоў: `-оў / -еў / -ёў / -аў`, `-віч / -іч`, `-скі / -цкі`, `-ка / -ко`, `-ін / -ын`, `-ук / -юк / -чук`, `-енка / -анка`, `-ік / -ык`, а таксама рэгіянальных суфіксаў (`-ёнак/-онак`, `-еня/-эня`, `-эйка/-ейка`, `-кевіч`, `-ман` і інш.).
   * Топ самых частых прозвішчаў для кожнай фіналі.

3. **⚔️ Тэрытарыяльнае спаборніцтва суфіксаў:**
   * Разлік дамінуючых арэалаў паміж 2–6 групамі фіналяў па ўсіх 118 раёнах Беларусі.
   * Вызначэнне лідэраў, маржы перавагі і памежных зон 50/50.
   * Візуалізацыя на выбар: ⬡ Гексаганальная плітка ці ⭕ Раённыя кругі.

4. **Рэйтынг шчыльнасці па 118 раёнах:**
   * Працэнтная доля гістарычных паселішчаў раёна, дзе зафіксавана шуканае прозвішча.
   * Падтрымка пошуку па масках з зоркай (`*`) і пытаннікам (`?`), напрыклад `Літв*`, `Ч*хо`.
   * Інтэрактыўны акардэон раёнаў са спісам вёсак і павелічэннем у адзін клік.

5. **Параўнанне прозвішчаў:**
   * Вывад да 7 прозвішчаў адначасова на карту з рознымі колерамі.
   * Магчымасць аб'яднання ў адзіны супольны арэал (напрыклад, *«Літвін, Ліцвін»*).

6. **Гістарычныя карты і падложкі:**
   * OpenStreetMap (сучасная).
   * 3-верстка Шуберта (XIX ст.).
   * 1-верстка (пачатак XX ст.).
   * РККА 500м (1930–1940-я гг.).
   * WIG 1 км (польская карта 1930-х).
   * 10-верстка Стральбіцкага.
   * Рэжымы адлюстравання: Кластары, Кропкі, Цяплавая карта (Heatmap), а таксама аўтападгрузка вёсак пры набліжэнні (зум ≥ 10).

7. **Экспарт і інтэграцыя:**
   * Кампактныя кнопкі хуткага экспарту ў **GeoJSON** і **CSV**.
   * Капіраванне гатовай аформленай спасылкі для артыкулаў Вікіпедыі ў адзін клік.

## 🚀 Хуткі запуск

### 1. Лакальна на камп'ютары (Python)

```bash
# Кланаваць рэпазіторый
git clone https://github.com/uladzcz/dapamozhnik-plus.git
cd dapamozhnik-plus

# Усталяваць залежнасці
pip install -r requirements.txt

# Запусціць сэрвер
uvicorn main:app --reload
```
Адкрыйце ў браўзеры: **http://127.0.0.1:8000**

*(База даных `dapamozhnik.db.zip` аўтаматычна распакуецца пры першым запуску).*

---

### 2. Запуск у Docker

```bash
docker build -t dapamozhnik .
docker run -p 8000:8000 dapamozhnik
```

---

### 3. Разгортванне ў воблаку (Render.com / Koyeb / Fly.io)

Рэпазіторый утрымлівае гатовы файл `render.yaml`. Каб запусціць сайт у інтэрнэце бясплатна:
1. Зайдзіце на [Render.com](https://render.com).
2. Націсніце **New +** → **Blueprint** і абярыце ваш рэпазіторый `dapamozhnik-plus`.
3. Праз 2 хвіліны сэрвіс разгорнецца і дасць пастаянны публічны адрас!
