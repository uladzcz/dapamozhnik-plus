# Службовыя скрыпты для збору і апрацоўкі даных (Data Tools)

У гэтай тэчцы сабраны інструменты, якія выкарыстоўваліся для першапачатковага парсінгу, узбагачэння і верыфікацыі архіўных звестак паселішчаў і прозвішчаў Беларусі:

* `scraper.py` — першапачатковы парсер архіўнага партала.
* `import_json.py`, `import_surnames.py` — імпарт і структурыраванне даных у базу SQLite.
* `full_surnames_collector.py`, `fetch_all_tar.py`, `expand_and_complete.py` — глыбокі рэкурсіўны абыход усіх магчымых прэфіксаў і літарных камбінацый.
* `find_missing_settlements.py`, `ingest_missing_settlements.py` — пошук і інтэграцыя ўсіх раней прапушчаных паселішчаў.
* `study_suffixes.py`, `analyze_map_suffixes.py` — аналітыка фіналяў і суфіксаў прозвішчаў.
* `verify_final.py` — скрыпт тэсціравання цэласнасці базы звестак.
